TEDx CUSAT 2026 Landing Page:
An animation-driven, responsive landing page for TEDx CUSAT 2026 that blends visual storytelling with interactive UI/UX, guiding users from introduction to speakers and ticket conversion through smooth, engaging transitions.
Features
	> Animated Intro Section
	•	Smooth entrance animation for TEDx branding
	•	Sets tone before user interaction
	> Dynamic Hero Section
	•	Tagline-driven design: “Between What Is and What’s Next”
	•	Particle-based animated background
	> Orbit-Based Past Events Showcase (Desktop)
	•	Circular motion layout for visual storytelling
	•	Continuous animation for engagement
	> Adaptive Mobile Experience
	•	Orbit transforms into swipe/auto slideshow
	•	Optimized for smaller screens without losing context
	> Speakers Section (Voices of 2026)
	•	Interactive cards with focus/hover states
	•	Swipe-based navigation
	> Countdown Timer
	•	Real-time countdown to event
	•	Clear CTA for ticket conversion
  > Call-to-Action (CTA)
  •	Strategically placed “Get Tickets” buttons
  •	Designed for visibility and conversion

Tech Stack

	•	CSS3 (Custom Styling + Animations)
	•	JavaScript (Vanilla JS)
	•	GSAP (GreenSock Animation Platform)
